# MacOSXArt
An ammonia tweak for Mac OS X Sequoia to load custom artwork based on Mac OS X Lion assets.

To install it, install Ammonia first from its GitHub page (and make sure your system is configured correctly for tweak injection, i.e. System Integrity Protection disabled with the arm64e ABI enabled for Apple Silicon users).

Then download the latest release PKG via GitHub Releases and simply install the package via Mac OS X's Installer. Log off and log back in to make the changes take effect from there.
